# ES 雜訊區間突破策略

以 Zarattini, Aziz & Barbon (2024) 的日內動能策略為基礎，改為只做多、跌破 VWAP 停損、可留倉過夜，並以 VIX 決定部位大小。
2016-12 至 2026-08 的回測中，Sharpe 1.13、最大回撤 −8.4%；同期 ES 買進持有為 0.72 與 −34.0%。

所有數字為回測結果，未經實盤驗證。

## 策略規則摘要

| 項目 | 規則 |
| --- | --- |
| 方向 | 只做多 |
| 進場檢查 | 每個整點與半點，開盤後第一個半小時不進場 |
| 進場條件 | 1 分 K 收盤價 > 雜訊區間上緣，且 ≥ 當日 VWAP |
| 正規盤停損 | 每 5 分鐘檢查，價格 < 當日 VWAP 即出場 |
| 留倉 | 收盤時價格仍 ≥ 當日 VWAP 就留倉過夜，隔天改用新一天的 VWAP |
| 夜盤停損 | 每 5 分鐘檢查，價格 < 前一天 VWAP × (1 − VIX/100/√252) 即出場 |
| 部位大小 | 槓桿 = min(4, 2% ÷ (VIX/100/√252))，進場時決定 |
| 交易成本 | 每邊 1 tick（0.25 點，含手續費與滑價） |

雜訊區間上緣：

```
上緣_t = max(今日開盤, 前日收盤) × (1 + σ_t)
σ_t    = (1/14) × Σ_{i=1..14} | 收盤_{d−i, t} ÷ 開盤_{d−i} − 1 |
```

詳細的文獻依據、樣本外檢驗、成本敏感度與限制請見報告。
